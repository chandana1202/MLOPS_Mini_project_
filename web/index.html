Safety and reliability controls

  • Input scan: injection and toxicity patterns checked before agents start.
  • Data contract: required fields, ranges and cross-field rules validated before a job is created.
  • Agent boundary: extractor reads free text; reasoner receives structured entities, never raw free text.
  • Output filter: blocks “approved” / “granted” wording and toxic content.
  • Provider resilience: 30 s model timeout; 3 retries with exponential backoff; Redis-backed breaker opens after 3 failures and resets after 30 s.
  • Agent loop limits: 8 steps, 8 tool calls, 60 s per run.

Architecture and deployment boundaries

Boundaries keep the browser and API independently deployable, isolate provider failures behind a worker breaker, let workers scale horizontally, and keep CPU/memory-heavy indexing separate. Health checks enforce Redis → indexer completion → worker and API startup.

Known limitations
